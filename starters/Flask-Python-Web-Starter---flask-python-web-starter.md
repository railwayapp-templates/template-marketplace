## About

Minimal Flask web starter with HTTPS and a pinned source repository commit.

This deployment fork provisions flask. Application domains and any authored TCP endpoints are generated for each new deployment. Database and queue services are private by default.

## What gets deployed

| Service | Source | Type |
|---------|--------|------|
| flask | [railwayapp-templates/flask](https://github.com/railwayapp-templates/flask) (branch: main) | Web service |
