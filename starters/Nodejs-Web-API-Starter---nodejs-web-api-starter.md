## About

Node.js app with an automatic HTTPS domain and pinned source commit.

This deployment fork provisions nodejs. Application domains and any authored TCP endpoints are generated for each new deployment. Database and queue services are private by default.

| nodejs | [alphasecio/nodejs](https://github.com/alphasecio/nodejs) (branch: main) | Web service |
