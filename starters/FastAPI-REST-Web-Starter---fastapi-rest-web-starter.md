## About

Python REST API starter with HTTPS and a pinned upstream source snapshot.

This deployment fork provisions FastAPI. Application domains and any authored TCP endpoints are generated for each new deployment. Database and queue services are private by default.

## What gets deployed

| Service | Source | Type |
|---------|--------|------|
| FastAPI | [railwayapp-templates/fastapi](https://github.com/railwayapp-templates/fastapi) (branch: main) | Web service |
