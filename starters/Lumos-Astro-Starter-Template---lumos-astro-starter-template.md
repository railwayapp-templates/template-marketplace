# Deploy Lumos Astro Starter Template on Railway

A component and styling framework for building Astro sites

[![Deploy on Railway](https://railway.com/button.svg)](https://railway.com/deploy/lumos-astro-starter-template)

## About

Lumos Astro Starter Template is a ready-to-use starting point for building websites with Astro and the Lumos framework. It provides Lumos components, styles, and project structure so you can quickly create fast, responsive, and accessible websites with Astro.

Deploying Lumos Astro Starter Template on Railway gives you a hosted Astro website without requiring server configuration. After deployment, Railway provides an automatically generated domain that you can use to access your website. You can also add a custom domain through your Railway project when you're ready to use your own domain.
