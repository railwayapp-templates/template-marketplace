## About

PraiseDynasty is an AI-assisted conversational sales operating system for
WhatsApp-first businesses. It combines a multi-tenant FastAPI backend,
Supabase/pgvector-powered RAG, and a six-state Sales Progression Engine to
qualify leads, follow up automatically, and move conversations toward a sale
— entirely over WhatsApp, with a Next.js dashboard for oversight and billing.

Hosting PraiseDynasty means running a multi-tenant FastAPI backend connected
to a Supabase Postgres database with pgvector enabled for RAG-based reply
generation, alongside an Evolution API instance that handles the WhatsApp
connection for each tenant. The backend runs the Sales Progression Engine,
which tracks each lead through a six-state follow-up playbook and triggers
automated messages and escalations. A Next.js dashboard gives each tenant
visibility into conversations, analytics, and billing, which is processed
through Paystack. Because it's multi-tenant, one deployment can serve
multiple WhatsApp-first businesses at once, each isolated by tenant.

## Environment variables

| Variable | Service | Default | Description |
| --------- | ------- | ------- | ----------- |
| `POSTGRES_DB` | Postgres | - | Name of the database Evolution API and other services should connect to. |
| `DATABASE_URL` | Postgres | - | 	Full internal Postgres connection string (used by services running on Railway's private network). |
| `POSTGRES_USER` | Postgres | (secret) | Username Railway creates for this Postgres instance. |
| `POSTGRES_PASSWORD` | Postgres | (secret) | Password for the Postgres root/admin user. Auto-generated by Railway. |
| `DATABASE_PUBLIC_URL` | Postgres | - | Publicly reachable Postgres connection string, for connecting from outside Railway's network (e.g. local dev tools). |
| `REDISHOST` | Redis | - | 	Internal hostname Railway assigns to this Redis instance. |
| `REDISPORT` | Redis | - | Port Redis listens on (default 6379). |
| `REDISUSER` | Redis | - | 	Username for authenticating to Redis (default is usually default). |
| `REDIS_URL` | Redis | - | 	Full internal Redis connection string used by services on Railway's private network. |
| `REDISPASSWORD` | Redis | (secret) | 	Password for the Redis instance. Auto-generated by Railway. |
| `REDIS_PASSWORD` | Redis | (secret) | 	Alias/duplicate of the Redis password, used by services expecting this variable name. |
| `REDIS_PUBLIC_URL` | Redis | - | Publicly reachable Redis connection string, for connecting from outside Railway's network. |
| `PORT` | evolution-api | - | Port the Evolution API server listens on inside the container. |
| `REDIS_URI` | evolution-api | - | 	Redis connection string used by Evolution API for session/state caching. |
| `SERVER_URL` | evolution-api | - | Public URL of this Evolution API deployment. Used to generate correct webhook and QR/connection URLs — set this to your Railway-assigned domain. |
| `CORS_ORIGIN` | evolution-api | - | Allowed origin(s) for cross-origin requests to the API. Use * to allow all, or a specific domain for tighter security. |
| `DEL_INSTANCE` | evolution-api | - | 	Time (or flag) controlling whether a disconnected WhatsApp instance is automatically deleted. |
| `QRCODE_LIMIT` | evolution-api | - | 	Maximum number of QR code generation attempts allowed per instance before requiring a restart. |
| `REDIS_ENABLED` | evolution-api | - | Whether Evolution API uses Redis for general caching (true/false). |

| `DATABASE_ENABLED` | evolution-api | - | 	Whether Evolution API persists data to a database (true/false). |

| `CACHE_REDIS_ENABLED` | evolution-api | - | 	Whether Redis-based caching is turned on for Evolution API (true/false). |

| `CACHE_REDIS_PREFIX_KEY` | evolution-api | - | Prefix added to all Redis cache keys created by Evolution API, to avoid collisions if Redis is shared. |
| `DATABASE_CONNECTION_URI` | evolution-api | - | 	Full connection string Evolution API uses to reach its Postgres database. |

| `CACHE_REDIS_SAVE_INSTANCES` | evolution-api | - | Whether WhatsApp instance state is persisted to Redis so instances survive restarts (true/false). |
| `CONFIG_SESSION_PHONE_CLIENT` | evolution-api | - | 	Client name identifying this app/session to WhatsApp (shown during the linking/QR process). |

## Configuration

- **TCP Proxies:** 5432
- **Volume:** `/var/lib/postgresql/data`
- **Start command:** `/bin/sh -c "rm -rf $RAILWAY_VOLUME_MOUNT_PATH/lost+found/ && exec docker-entrypoint.sh redis-server --requirepass $REDIS_PASSWORD --save 60 1 --dir $RAILWAY_VOLUME_MOUNT_PATH"`
- **TCP Proxies:** 6379
- **Volume:** `/data`
- **Healthcheck:** `/health`
- **Networking:** Public domain with automatic HTTPS
