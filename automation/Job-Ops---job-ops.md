## About

Job Ops is an automated job-operations platform that aggregates opportunities, runs extractors, and powers a searchable backend for job workflows. This template deploys a production-ready Job Ops stack on Railway with sensible defaults and an easy path to scale.

[![Deploy on Railway](https://railway.com/button.svg)](https://railway.com/deploy/Lp9q5l?referralCode=C3Uv6n&utm_medium=integration&utm_source=template&utm_campaign=generic)

Job Ops runs as a Node.js orchestrator service with Python-powered extraction capabilities, browser automation support, and persistent data storage for generated assets such as PDFs. Railway simplifies deployment by packaging the full runtime into a single service while connecting managed dependencies for database, cache, browser automation, and object storage.

## Environment variables

| Variable | Default | Description |
| --------- | ------- | ----------- |
| `PORT` | 3001 | Listen port. Must match the domain's target port. |
| `MODEL` | google/gemini-3-flash-preview | Model name sent to that provider. |
| `DATA_DIR` | /app/data | Where jobs.db and the generated PDFs live. Must be the volume's mount path. |
| `CODEX_HOME` | /app/data/codex-home | Codex CLI login directory, kept on the volume so the login survives redeploys. |
| `APIFY_TOKEN` | (secret) | Apify token for the Seek extractor. |
| `LLM_API_KEY` | (secret) | Key for the chosen API provider. |
| `LLM_PROVIDER` | - | atlascloud, openrouter, orcarouter, requesty, openai, gemini, gemini_cli, claude_cli or codex. The CLI providers log in from the UI. |
| `RXRESUME_URL` | - | Base URL of a self-hosted Reactive Resume. Empty uses the hosted service. |
| `ADZUNA_APP_ID` | - | Adzuna extractor credentials. |
| `ADZUNA_APP_KEY` | - | Adzuna extractor credentials. |
| `XDG_CACHE_HOME` | /app/data/cache | Cache directory, kept on the volume so the LaTeX bundle is not re-downloaded on every deploy. |
| `BASIC_AUTH_USER` | (secret) | With BASIC_AUTH_PASSWORD, puts the app and API behind HTTP basic auth. Unset, the app is open. |
| `RXRESUME_API_KEY` | (secret) | Reactive Resume v5 API key, for CVs rendered by rxresu.me instead of locally. |
| `UKVISAJOBS_EMAIL` | - | UKVisaJobs extractor credentials. |
| `BASIC_AUTH_PASSWORD` | (secret) | See BASIC_AUTH_USER. |
| `UKVISAJOBS_PASSWORD` | (secret) | UKVisaJobs extractor credentials. |
| `GMAIL_OAUTH_CLIENT_ID` | - | Gmail tracking integration. |
| `JOBOPS_PUBLIC_BASE_URL` | - | Public URL used in links generated by background jobs. |
| `GMAIL_OAUTH_REDIRECT_URI` | - | Defaults to <request-origin>/oauth/gmail/callback. |
| `GMAIL_OAUTH_CLIENT_SECRET` | (secret) | Gmail tracking integration. |
