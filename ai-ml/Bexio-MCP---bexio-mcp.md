# Deploy Bexio MCP on Railway

Bexio MCP server with token-protected HTTP access to your business data.

[![Deploy on Railway](https://railway.com/button.svg)](https://railway.com/deploy/bexio-mcp)

## About

Connect your bexio workflows with compatible AI applications and automation tools. Bexio MCP is a community-developed integration offering tools for contacts, invoices, quotes, accounting, projects and more. This Railway template helps you host the MCP server centrally, with token-protected HTTP access to your own bexio account.

Hosting Bexio MCP on Railway provides a central HTTP service for your integrations. Supply your bexio Personal Access Token and connect your applications using the separate HTTP authentication token generated by the template.

The startup configuration checks credentials, timezone and file storage before launching the server. Attach a persistent volume at `/data`; this is required by the configured startup checks. The default timezone is `Europe/Zurich`, while a custom `TZ` value takes precedence.

Use one service instance with the attached volume. Available operations depend on your bexio permissions and subscribed modules. No separate application database is required.

## Environment variables

| Variable | Default | Description |
| --------- | ------- | ----------- |
| `TZ` | - | Optional. Leave empty to use Europe/Zurich at runtime, including daylight-saving changes. A configured timezone takes precedence. To use an existing shared project variable named TZ, enter ${{shared.TZ}}. Use an IANA timezone name. Application logger timestamps remain ISO UTC. |
| `PORT` | 8080 | Preconfigured HTTP listening port. The start command validates and passes this value to the server. Configure public networking with the same target port. |
| `TMPDIR` | /tmp | Temporary directory available during the build. At runtime, the start command changes TMPDIR to BEXIO_FILE_DIR/tmp after the volume is mounted. Stored downloads are not automatically deleted. |
| `NODE_ENV` | production | Production runtime mode. Required build dependencies are explicitly installed by RAILPACK_INSTALL_CMD. |
| `BEXIO_BASE_URL` | https://api.bexio.com/2.0 | Bexio API base URL. Keep the default for normal use. To restore the application default, delete this variable entirely; an explicitly empty value does not restore the default. |
| `BEXIO_FILE_DIR` | - | Automatically uses the attached persistent volume for server-side files. Requires a volume mounted at /data. Startup creates /data/files and /data/files/tmp with restricted permissions. Local file paths refer to the server, not the client computer. |
| `BEXIO_API_TOKEN` | (secret) | Required manual input. Enter your Bexio Personal Access Token from https://developer.bexio.com. The token must have the permissions needed for your workflows. |
| `BEXIO_ENABLE_UI` | false | Interactive panels are available only in stdio mode. Keep false for this HTTP deployment. This setting does not enable panels on the HTTP endpoint. |
| `BEXIO_API_TOKENS` | (secret) | Optional additional company tokens. Leave empty for a single company. Accepts CompanyA:tokenA,CompanyB:tokenB or a JSON object. The active company is shared across HTTP requests; use separate services for concurrent company isolation. |
| `BEXIO_HTTP_TOKEN` | (secret) | Automatically generated authentication token for this server. Clients must send Authorization: Bearer <this value>. Separate from your Bexio API token. No manual input needed. |
| `RAILPACK_BUILD_CMD` | npm run build | Build the TypeScript server and bundled UI assets. The persistent volume is not available during the build. |
