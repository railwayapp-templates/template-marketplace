## About

Edict runs nine specialized AI agents that divide and conquer your work. Built on the Chinese Three Departments Six Ministries model, each agent handles one domain — research, coding, writing, review, and more — while a real-time dashboard shows everything happening.

Single service with a compose file. The web dashboard runs on the default port. Configure your preferred LLM provider via environment variables.
