# Deploy Metabase Serialization on Railway

export/import dashboards as YAML

[![Deploy on Railway](https://railway.com/button.svg)](https://railway.com/deploy/metabase-serialization)

## About

Metabase Serialization is a Pro/Enterprise feature, not an OSS switch. YAML export/import for collections, dashboards, and settings lives behind a license check inside the JAR. This Railway template runs OSS `metabase/metabase`: full open-source BI, no serialization.

If you came for `java -jar metabase.jar export` or `/api/ee/serialization/*`, stop. Those endpoints are Pro/Enterprise only; OSS returns 404 or a license prompt. This listing still gives you a production OSS BI stack—Postgres-backed app DB, questions, dashboards, and collections—ready if you later add a license on a Pro/Enterprise JAR.

## What gets deployed

| Service | Source | Type |
|---------|--------|------|
| metabase/metabase | `metabase/metabase` | Web service |
| Postgres | `ghcr.io/railwayapp-templates/postgres-ssl:18` | Database |
