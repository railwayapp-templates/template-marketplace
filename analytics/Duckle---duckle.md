## About

Duckle is an open-source ETL/ELT platform built on DuckDB. Connect to 385 data sources, build pipelines in a visual editor or SQL, and transform data without a separate compute layer. No per-row billing.

Duckle runs as a Rust service with a web-based pipeline editor. Deploy from this template and connect your data sources. DuckDB handles transforms fast without needing a dedicated warehouse.
