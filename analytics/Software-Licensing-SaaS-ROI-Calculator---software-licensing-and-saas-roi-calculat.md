## About

Software Licensing & SaaS ROI Calculator is an open-source IT budgeting tool and programmatic REST API. It calculates total cost of ownership (TCO) comparisons between one-time perpetual software licenses and recurring SaaS subscription plans over 1 to 5-year horizons.

Deploying this microservice on Railway provides an instant web dashboard and headless JSON API running on high-performance Node.js with automated Nixpacks containerization. It requires zero external databases, boots in under 2 seconds, and includes built-in health check monitoring for 99.9% uptime.
