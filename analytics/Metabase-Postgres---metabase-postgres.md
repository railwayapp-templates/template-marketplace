# Deploy Metabase Postgres on Railway

connect Postgres warehouses to Metabase

[![Deploy on Railway](https://railway.com/button.svg)](https://railway.com/deploy/metabase-postgres)

## About

Pointing Metabase at a Postgres warehouse takes four minutes, until a sync scan pins your prod primary for twenty. The difference between a demo and a quarter-long deployment is in the details: read replicas, schema filters, statement timeouts, and keeping Metabase's own app database off your analytics box.

The first-boot wizard creates your admin user, and that's when most people open Admin → Databases and type in their prod primary hostname. Resist. The Postgres you add there is the warehouse: your orders, events, or customer tables. It is not the companion Postgres that stores Metabase's users, dashboards, and saved questions. The template gives you the app side; this guide is about making the warehouse connection production-safe.

## What gets deployed

| Service | Source | Type |
|---------|--------|------|
| metabase/metabase | `metabase/metabase` | Web service |
| Postgres | `ghcr.io/railwayapp-templates/postgres-ssl:18` | Database |

## Environment variables

| Variable | Service | Default | Description |
| --------- | ------- | ------- | ----------- |
| `PORT` | metabase/metabase | 3000 | PORT |
| `MB_DB_HOST` | metabase/metabase | - | MB_DB_HOST |
| `MB_DB_PASS` | metabase/metabase | - | MB_DB_PASS |
| `MB_DB_PORT` | metabase/metabase | - | MB_DB_PORT |
| `MB_DB_TYPE` | metabase/metabase | postgres | MB_DB_TYPE |
| `MB_DB_USER` | metabase/metabase | (secret) | MB_DB_USER |
| `MB_SITE_URL` | metabase/metabase | - | MB_SITE_URL |
| `MB_DB_DBNAME` | metabase/metabase | - | MB_DB_DBNAME |
| `MB_PASSWORD_COMPLEXITY` | metabase/metabase | (secret) | MB_PASSWORD_COMPLEXITY |
| `ENABLE_ALPINE_PRIVATE_NETWORKING` | metabase/metabase | true | ENABLE_ALPINE_PRIVATE_NETWORKING |
| `POSTGRES_DB` | Postgres | railway | Default database created when image is started. |
| `DATABASE_URL` | Postgres | - | URL to connect to Postgres database. |
| `POSTGRES_USER` | Postgres | (secret) | User to connect to Postgres DB |
| `POSTGRES_PASSWORD` | Postgres | (secret) | Password to connect to DB |
