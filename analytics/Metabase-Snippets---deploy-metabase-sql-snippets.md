# Deploy Metabase Snippets on Railway

Reusable SQL snippets for consistent metrics

[![Deploy on Railway](https://railway.com/button.svg)](https://railway.com/deploy/deploy-metabase-sql-snippets)

## About

This Railway template runs Metabase with managed Postgres for self-hosted open-source BI. Metabase Snippets are reusable SQL fragments that keep metric definitions consistent across native queries. No more re-typing joins and filters per card.

Self-hosting Metabase Snippets on Railway means your reusable SQL snippets, query results, and warehouse credentials stay in a project you control. Your analytics databases stay separate and connect after first-boot setup.

## What gets deployed

| Service | Source | Type |
|---------|--------|------|
| Postgres | `ghcr.io/railwayapp-templates/postgres-ssl:18` | Database |
| metabase/metabase | `metabase/metabase` | Web service |

| `DATABASE_URL` | Postgres | - | URL to connect to Postgres database. |
| `POSTGRES_USER` | Postgres | (secret) | User to connect to Postgres DB |
| `POSTGRES_PASSWORD` | Postgres | (secret) | Password to connect to DB |
| `PORT` | metabase/metabase | 3000 | PORT |
