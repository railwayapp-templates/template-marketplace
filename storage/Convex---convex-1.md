# Deploy Convex on Railway

Reactive backend and dashboard with persistent SQLite and HTTP actions.

[![Deploy on Railway](https://railway.com/button.svg)](https://railway.com/deploy/convex-1)

## About

Self-host Convex with its web dashboard, a persistent SQLite database, and file storage on a Railway volume.

This template includes two services using pinned official Convex images:

| Service | Public port | Purpose | Persistent storage |
| --- | ---: | --- | --- |
| convex-backend | 3210 | Realtime API and HTTP actions under `/http` | `/convex/data` |
| convex-dashboard | 6791 | Administration dashboard | None; data lives in the backend |

The backend has a generated instance secret, a `/version` readiness check, and a required persistent volume. The dashboard explicitly listens on `0.0.0.0`. The dashboard and API use HTTPS domains generated by Railway.

## Environment variables

| Variable | Service | Default | Description |
| --------- | ------- | ------- | ----------- |
| `PORT` | convex-dashboard | 6791 | Container listener and public domain target port. |
| `HOSTNAME` | convex-dashboard | 0.0.0.0 | Listen on all container IPv4 interfaces so Railway can reach the dashboard. |
| `NEXT_PUBLIC_DEPLOYMENT_URL` | convex-dashboard | - | Public HTTPS API origin used by the dashboard browser. Do not use a private service hostname. |
| `PORT` | convex-backend | 3210 | Container listener and public domain target port. |
| `INSTANCE_NAME` | convex-backend | self-hosted-convex | Stable instance identity. Preserve with the volume and instance secret. |
| `DISABLE_BEACON` | convex-backend | true | Disable the optional upstream telemetry beacon. |
| `INSTANCE_SECRET` | convex-backend | (secret) | Generated 32-byte hexadecimal instance secret. Keep private and preserve with backups. |
| `CONVEX_SITE_ORIGIN` | convex-backend | - | Public HTTP-action origin; /http routes through the API listener on port 3210. |
| `CONVEX_CLOUD_ORIGIN` | convex-backend | - | Public HTTPS API origin used in generated storage URLs and callbacks. |
| `CONVEX_SELF_HOSTED_URL` | convex-backend | - | Public API origin for self-hosted CLI configuration. |
| `DISABLE_METRICS_ENDPOINT` | convex-backend | true | Disable unauthenticated public metrics exposure. |
