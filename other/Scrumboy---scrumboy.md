## About

Scrumboy is a kanban and project management tool with shareable boards, voice commands, and MCP support for AI agents. Built in Go, it starts fast and uses minimal memory.

Scrumboy runs as a single Go binary with SQLite storage. No external database needed. Deploy from this template and your team gets shareable kanban boards from any browser. Voice commands let you update tasks hands-free, and AI agents can read and update your board through its MCP server.
