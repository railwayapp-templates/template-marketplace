[![Deploy on Railway](https://railway.com/button.svg)](https://railway.com/deploy/fair-wild)

## About

Deploy a PostgreSQL 16 database on Railway using the official Docker image. Minimal, production-ready configuration for your projects.

This template runs PostgreSQL 16 in a Docker container on Railway with persistent storage via a volume. Connection variables are automatically provided so you can wire it up to any service in your project.
