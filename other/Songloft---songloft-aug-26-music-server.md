## About

Songloft is a music server with a plugin system. Upload your MP3s and FLACs, organize them, and stream from any browser or phone. No ads, no recommendations you didn't ask for.

Go binary in a Docker container. Stores music and app data on a volume. Port 58091. Admin credentials set via environment variables.
