## About

Notlink is a URL shortener built in Rust. It generates short links, tracks clicks, and serves redirects fast. Self-hosted so you own your links and data with no per-link limits.

Notlink runs as a single Rust binary. Deploy from this template and start shortening URLs immediately. Rust means it handles high traffic with minimal resource usage.
